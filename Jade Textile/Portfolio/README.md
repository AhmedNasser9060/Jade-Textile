# Ahmed Nasser Eldin — AI for Garment Manufacturing

Single-deployment Vercel portfolio containing the main profile and three detailed project sites:

- `projects/bulbul/` — mobile material-flow robot case study
- `projects/stitchops/` — garment workforce and production analytics
- `projects/factoryvision/` — responsible computer-vision workforce demonstrator

## Deploy on Vercel

1. Import the `Portfolio` folder as a new Vercel project.
2. Select **Other** as the framework preset.
3. Leave the build command empty.
4. Set the output directory to `.`.
5. Deploy.

The Bulbul video uses a public Google Drive file. Ensure that file remains shared as **Anyone with the link can view**.
