# Bulbul — Portfolio Case Study

A lightweight, responsive portfolio page for the Bulbul mobile-robot prototype. The page separates the documented healthcare prototype from the proposed garment-factory application.

## Preview locally

Open `index.html` directly, or run any static server in this folder, for example:

```powershell
npx serve .
```

## Deploy to Vercel

1. Create a new Vercel project.
2. Select this folder as the project root.
3. Choose **Other** as the framework preset.
4. Leave the build command empty and use `.` as the output directory.
5. Deploy.

The prototype video streams from the supplied public Google Drive link and is positioned at `01:33` by default. Keep its sharing setting on **Anyone with the link can view**.

## Content note

`assets/garment-factory-concept-v3.png` is an AI-generated visualization of a proposed garment-factory scenario. It is labeled as such on the page and is not presented as a photograph of a deployed system.
